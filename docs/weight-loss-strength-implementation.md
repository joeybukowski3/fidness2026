## Progression

Weeks 1–2: establish loads and knee tolerance, 2–3 RIR. Weeks 3–4: normal lifts at 2 RIR, appropriate final sets at 1–2 RIR. Week 5: normal lifts at 1–2 RIR. Monday, core control, and Friday light lower remain 2–3 RIR. Week 6: strength/core sets 3→2 and 2→1, 3–4 RIR, suggest 10–15% load reduction; retain mobility and easy/moderate conditioning. Week 7 repeats week 1. Double progression is guidance, not an automated load calculator; the existing logger records effort rather than numeric RIR on each individual set.

Monday conditioning 15–18 min (18-min budget), RPE 5–6. Tuesday bike 3 easy / 15 moderate / 2 easy, no HIIT. Wednesday optional incline walking approximately 2.5–3.2 mph at 3–6%, RPE 5–6; use bike when not tolerated. Thursday 5 easy / 35 steady at RPE 5–6 / 5 easy. Friday approximately 15 min at RPE 5–6. Stationary/recumbent bike fallback throughout. No running or required fasting.

Knee-sensitive work uses tolerated range only; avoid forced deep flexion, stop/substitute sharp pain. Leg press can use tolerated glute bridge or be skipped. This is training guidance, not knee diagnosis/treatment.

## Selection, persistence, and compatibility

The registry and state-schema default now point to this program. Fresh/unused installations start it on the current Monday. Established and explicitly selected programs remain selected; use Program Management to select the new program and Set as Default to save its default preference. Switching programs does not remove history or existing scoped workout state. Old program templates and the performance definitions remain available unchanged. Pre-program unscoped workout-state fallback is restricted to the legacy program.

Schema version remains 2; no mandatory fields or destructive migration. New history rows add optional programId/programWeek/activityId/exerciseId. Cardio rows use existing time/speed/incline/distance fields and optional category; older strength/history rows need no conversion. Bike resistance is unsupported and no new resistance schema was invented. Strength logging retains its existing behavior.
